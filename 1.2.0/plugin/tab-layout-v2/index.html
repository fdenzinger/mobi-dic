    Map Layout QGIS

    Map Layout¶

    The Map Layout tab builds finished maps (single page, multipage report or panel grid; A4 to A2, Letter or custom, portrait or landscape) of DIC result layers, composed like a cartographic print product.

    The Map Layout tab in the sidebar holds this builder.

    Composition¶

    Settings¶

    The settings are grouped like in Results: Select data (folder, data type, layer, report type and the maps of a multipage report) and Page & title (page size and orientation, title, subtitle, logos) are open; everything else is in the collapsed Advanced options group with the sub-groups Map settings, Arrows, Colours & ranges and Locator, method & footer, whose headers show their current state (for example "Map settings — swisstopo · scale 1:5'000 · frame").

    The settings are remembered between QGIS sessions (page size and orientation, frame, arrows, colormaps and ranges per component, locator, key figures, method, footer note, report options). The folder, the selected layer and the maps ticked in the grid are not. The panel is also usable in a narrow dock: fields shrink, and the Maps grid scrolls sideways.

    Section Option Description
    Data Directory, Data type, Result layer Folder of a DIC run (scanned automatically); Data type Displacement (components and DIC input images), or Velocity, which switches the layer list and the Maps grid (a note shows how many files of the other type are hidden); and the result raster to map.
    Report Single page (selected layer), several pages (one map per page) or a panel grid (several maps per page, see below): every map switched on in the Maps grid, the same toggle grid as in Results (rows = image pairs, columns = components and, if exported, the DIC input images: hillshade, gradient magnitude and direction, primary and secondary). Click a cell, a row or a column header to switch maps on or off; the buttons All / Results / DIC inputs / None select in bulk. Pages are ordered by image pair, then component. By default the components of the selected layer's pair are on. Optional summary page first: a table of all maps (dates, maximum, mean, 95th percentile), small previews of the first maps (overview) and the method text. By default a component has the same colour range on all its pages (comparable time steps); input images share one grey stretch per kind. Everything is one layout; PDF export writes one multi-page file, PNG export one file per page. Arrows are drawn only from the sparse points of the same run and dates; pages without a matching file get no arrows (a note appears under the buttons).
    Panel grid Report type with several maps per page (A4 to A2, Letter or custom size). All panels share one extent and scale, so they are directly comparable. With One page per image pair every pair starts a new page with its maps together. Columns and rows can be set (Auto picks a good fit; with Auto the maps are split over pages of at most max per page panels). If every panel shows the same component with the same colour range (time steps), one colour bar sits at the bottom of the page; otherwise each panel has its own small colour bar. The scale bar and north arrow are in the first panel of each page; the reference arrow and the background attribution are in the bottom band. The summary page works as for several pages.
    Title block Title, Subtitle, Logo, MOBI-DIC logo Filled in from the component and run (dates and interval); edit freely. The MOBI-DIC logo (on by default) sits in the top right corner; an optional extra logo, e.g. your institution, goes to its left.
    Colours Components table, Round range, Opacity One row per component found in the folder with its own colormap (default: the usual one of the component) and range: Percentile, Min–max (calculated from the layer, shown for the selected layer), Fixed (Settings default) or Custom with Min and Max. Round range to nice values rounds calculated ranges outwards and puts a colour bar tick at every step (0.093 – 11 becomes 0 – 12, ticks every 2). Settings are remembered per component while you work.
    Map Background, Multiply Input image or DEM hillshade of the Input / Output tab, or a swisstopo / OpenStreetMap service; Multiply blends the result over the background.
    Arrows Direction arrows from the sparse points, drawn on the XY and XYZ components only, with a reference arrow in the legend.
    Map extent, Extent padding Data extent (default), Current map canvas view (the part of the QGIS canvas you see now, used for all pages) or Extent of a file (bounding box of a GPKG / SHP / KML / … polygon, e.g. an area of interest). Padding is added around it; a fixed scale centres on it.
    Extent padding Space around the extent.
    Frame style Look of the coordinate frame: thin zebra (default), zebra, ticks inside / outside, line only, grid lines or grid crosses inside the map.
    Map scale Auto fits the data into the map (the scale it would use is shown next to the box); a fixed scale 1 : N centres the map on the data and uses exactly that scale (the layout is in mm, so 1 : 5000 shows 5 m per mm). Data that does not fit is cropped and a note appears. All pages of a report use the same scale.
    Tick labels on Which edges of the map get coordinate labels (left, bottom, top, right; default left and bottom). The right edge reserves a 6 mm strip. Top / right are taken over by the lat/lon frame when that is on.
    Key figures Maximum, mean, 95th percentile and valid area of the layer in a small table (maximum, mean and 95th percentile of the absolute value for signed components).
    Arrow source, anchor, filter Draw the arrows from the raw sparse points or from the coherence- / neighbour-filtered GeoPackage of the same run (if it exists), starting at or centred on the point, optionally hiding arrows whose direction deviates more than a set angle from their neighbours or whose displacement is below or above a limit. Arrow thickness and a thin outline in the opposite colour (on by default) keep them readable on dark and light areas. The colours of the result are not filtered.
    Round range Rounds the calculated Percentile / Min–max range outwards to nice values and puts a colour bar tick at every whole step (0.093 – 11 becomes 0 – 12, ticks every 2).
    Page Size A4, A3, A2, Letter or custom (width × height in portrait) and landscape (default: map left, legend / locator / method in a column on the right) or portrait (map on top, legend / locator / method below). Fonts keep their size, so a larger page gives a larger map.
    Coordinate frame, Lat/lon frame, Scale bar, North arrow Frame with coordinate labels in the map CRS (left and bottom), an optional second frame in latitude / longitude (degrees and minutes, top and right), scale bar with scale, north arrow. Hidden in Camera mode (pixel coordinates).
    Locator, method and footer Locator map Small overview map with the mapped area marked in red, from a swisstopo or OpenStreetMap service.
    Method text, Footer, Footer note Processing description and the footer line, taken from the run tag; an optional note (data source, author).

    Build map layout creates the layout and opens it in the Layout Designer; Export PDF… and Export PNG… build it and write the file directly (300 dpi).

    Camera mode

    Camera results have no coordinate system: the layout has no coordinate frame, scale bar, north arrow or locator map, and units are pixels.
